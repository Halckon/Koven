## 1. 范围

提供 `kovenc doc <path>`，复用 Lexer/Parser 抽取单文件顶层普通函数的源码声明。
JSON schema/version、Guide 与编译器版本、按源码顺序的函数、位置、原始签名、参数名称、
类型与声明模式可追溯。无标记保留 default，显式 borrow/own/inout 保留拼写，不推导类型。
返回标注包含于原始签名，不伪造省略标注。声明索引明确 syntax-only，不承诺类型、所有权或执行通过。
顶层非函数及扩展函数显式列为 omitted；类成员、完整标准库、doc comment、网页呈现和 project 抽取不在首片。

## 2. 示例协议

API 示例库存引用已有教程 ID、该教程已有源码路径与唯一顶层函数名称，不复制源码或运行结果。
先用真实 doc 命令抽取并校验声明存在且唯一，再通过现有教程 checker/run_case 验证完整行为。
输出包含 schema/version、Guide、源码 SHA256、教程身份与抽取声明；版本与摘要描述实际输入，
不将用户声明的 Git 版本伪装成验证过的工具链。先交付 greeting 与 inspect 两个现有教程关联。
无效/重复/空库存、planned/诊断例、缺失源码或声明、命令失败不能产出成功目录。

## 3. 失败与确定性

非法语法沿用完整 human/JSON Lines 诊断，退出2、stdout为空；IO和用法错误亦退出2。
不执行待抽取源码、不改输入、不生成文件；语义错误的可解析源码允许索引并明确未验证。
位置采用 UTF-8 byte range 与既有1基字符行列；路径无临时绝对目录，重复导出字节一致。
示例验证在原 runner 的隔离临时目录执行，任何失败传播非零，不以 mock 代替真实双宿主验收。
