## 1. Goal 与边界

交付两道本地练习，覆盖可变 place 和默认 Borrow 与 own 的区别。每题有失败起点、提示、
可执行答案及精确 stdout/stderr/exit 合同。使用现行能力，复用教程 run_case，不改语言或编译器。
M2 按已验收能力独立启动本地切片；不宣称 M0/M2 整体完成，不依赖网页执行、文本/IO候选或用户测试框架。

## 2. 行为

练习源码与 JSON 合同存于 docs/tutorials/kovenlings；按稳定 ID 寻址，无在线或远程依赖。
默认验证全部 starter 的预期编译诊断、全部 solution 的 build/直接运行/run 完整结果。
用户可复制 starter 到仓库外修改，以 --exercise ID --source FILE 对答案合同校验，错误结果非零退出。
提示只描述已启用规则；不要求匹配答案源码，符合行为合同的其他解法亦可通过。
空库存、重复/非法ID、缺文件/提示或不完整合同失败，不能把无测试显示为通过。
验证在独占临时目录进行，不修改用户文件；非法 starter 不得留下产物。

## 3. 非目标

不提供交互 TUI、watch、自动修复、进度持久化、项目题、运行不受信任源码的沙箱或网页入口。
不把两道练习称为完整 Kovenlings，不改变现有教程数量与 oracle。

## 4. 验收

- [x] loader/选择/失败传播负例先失败再实现；复用 run_case，无第二套进程执行器。
- [x] 两 starter 精确诊断、两答案 build/直接运行/run 在真实 CLI 上通过；错误学习者源码被拒绝。
- [ ] 提示与答案独立复核，双平台 CI 运行真实练习，不以 mock 代替。
- [ ] 文档、库存、生成图与 CI 路由同步，最终 CI 通过后归档。
