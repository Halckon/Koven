# Spec 冻结库存

> **性质**：生命周期库存声明 · **状态**：current · **读取时机**：登记 active Spec 或归档完成 Spec 时 · **唯一真源**：本文件的 active/archive 编号集合

本声明独立于目录扫描和导航链接；每次新增、移除或迁移 active/archive Spec，必须同步更新
对应数组和实际文件、状态、索引及依赖图。原正文与验收证据遵守[文档治理](../AGENTS.md)。

## 声明格式

全文恰好一个 JSON fenced block，只允许 `active`、`archived` 两个数组；元素为四位 ASCII
编号，不重复且两数组不相交。文件及父目录不得使用符号链接，文件必须为无执行位的普通文件。
缺失、不可读、编码或格式错误直接使文档门禁失败；不能用空集合、目录扫描或旧库存回退。

本文件只声明编号；生命周期状态、全局唯一、标题一致性及库存双向核对仍由
`scripts/check_docs.py` 强制校验。已登记 archived 项保持 `done`；声明不能放宽此规则。
draft 按版本库存与 ADR 库存仍在 checker 中，本次不迁移。该文档不会为 Spec 提供实施授权。

实现合同见 [SPEC-0304](../archive/specs/0304-spec-archive-inventory.md)。
