## 共用最小 API 合同候选

| 能力 | 需表达的接口责任 | 当前缺口／实施前决定 |
|---|---|---|
| 文本与字节 | UTF-8 读取、行拆分、字段分隔、数字解析与输出格式化 | 当前最小 String 表面不能推断 length／slice／builder；索引单位、非法字节处理、换行与返回 owner／borrow 待定 |
| 可恢复错误 | IO 与解析失败返回值、定位上下文和错误传播 | Pair／Result 的普通入口加载与传播不能仅凭 Guide 推论；错误类型、传播和 CLI 退出方式须闭合 |
| 集合 | 聚合、查找、更新和按指定顺序输出 | 复用现有 Map 与顺序集合；缺少排序时必须显式设计，不能依赖哈希迭代或假设 Kotlin API |
| 文件与目录 | 读取／写入、目录枚举、显式关闭、失败后清理 | 同步阻塞；显式 close 失败如何报告、析构是否丢弃错误须定义，禁止凭 RAII 猜测 |
| 路径 | 拼接、显示、枚举的稳定相对路径 | 宿主非 UTF-8 路径、符号链接、权限和排序规则待契约定义 |
| 测试与进程 | 输入 fixture、断言、失败位置、stdout／stderr／退出状态 | 不能假定 main 返回 Int 或 Result；退出行为需现行合同允许或新语义批准 |

每个正式 API 合同还必须写清参数 borrow／own／inout、返回值来源、借用失效点、分配／复制、
错误与 Abort 边界、跨平台差异，并附普通 single／project 正反例。未经批准不写占位 public API。

## 日志统计器

目标：读指定 UTF-8 文本，按行提取级别与计数，输出稳定顺序的统计报告。

```text
参数取得输入路径 → 打开并读取 → 按行解析 → 聚合计数 → 稳定格式输出
失败 → 带文件／行位置的诊断 → 已打开资源清理 → 失败退出
```

- 最小输入合同候选：每行“级别 空格 消息”，级别固定 INFO／WARN／ERROR；输出按此固定顺序，避免首片强依赖通用排序。
- 成功验收：空文件、中文消息、三种级别、多行、末尾无换行、大于单行的输入。
- 失败验收：文件不存在／不可读、未知级别、非法编码、计数溢出；具体错误策略由 Spec 冻结。
- 前置：行处理、比较、整数格式化、Map 及 IO；不需要通用 iterator、线程或 HTTP。

## 目录清单工具

目标：列出目录文件并输出稳定可检查的清单；首片不强制 JSON 编码库。

```text
解析目录参数 → 枚举条目 → 取得必要元信息 → 稳定排序 → 输出清单
失败 → 指明条目与原因 → 释放目录／文件资源 → 按已批准策略退出
```

- 输出字段候选：相对路径、条目类型、文件大小；转义分隔符和换行的方式必须先冻结。
- 成功验收：空目录、中文／空格路径、普通文件和子目录；相同输入的输出稳定。
- 失败验收：权限不足、枚举过程中条目消失、非 UTF-8 路径；符号链接、递归深度与部分成功策略待定。
- 前置：目录／元信息／路径、排序或等价稳定算法；不自行把递归／跟随链接设为默认。

## CSV 校验器

目标：按冻结的最小列规则校验文本并报告行列错误，不声称支持所有 CSV 方言。

```text
读取输入 → 按批准的 CSV 子集解析 → 校验列数和指定数字列
→ 输出错误列表及统计 → 成功／失败退出 → 资源清理
```

- 正式 Spec 必须选择分隔符、引号转义、跨行字段、表头、空值和换行策略；此处不默认 RFC 全兼容。
- 成功验收：中文字段、空字段、边界数字和合法转义（若属于选定子集）。
- 失败验收：列数不符、非法数字、未闭合引号（若支持引号）、编码失败及输出写入失败。
- 前置：文本解析、数字与错误定位、IO 和测试 runner；CSV 逻辑先用 Koven 写在示范程序，不提前拆库。
