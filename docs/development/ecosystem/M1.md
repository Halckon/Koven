## 联合验收与完成条件

无源码 checkout、无需 Cargo 构建编译器的双宿主环境安装候选包；通过公开 CLI 构建并测试三个工具，核 stdout、stderr、退出状态和资源清理。

所有子项必需。测试基础与安装可先推进，最终必须接真实示范程序。线程允许本预览延期；不附带网络库、脚本新语法或公共 FFI。
