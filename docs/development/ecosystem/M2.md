## 联合验收与完成条件

浏览器修改既有教程并真实运行；覆盖编译失败、运行失败、超时超限及版本不可用；分享在另一环境复现；文档和练习来源可追溯。

该里程碑整体可选，但声称其 completed 前需完成列出的子项和联合验收。首版服务端 native；不做账户、任意依赖、完整在线 IDE 或 WASM。
