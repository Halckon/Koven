# N1a std receiver take 与 stable short-range root 清理收据

2026-10-10 UTC；基线 3ac650b；待父线程独立 review / commit。源码编辑已停止。

## 交付

1. `crates/lang-std/koven/algorithms/ranges.ko` 增加真实 List<T>.take / View<T>.take 两个 Borrow receiver wrapper，body 只调用既有 `take(this,count)`。负数 Abort、0、超 size clamp 均复用顶层算法，不复制计数逻辑。
2. std loader 已对真实加载 SourceId 分别授予 producer / extension 权限，无需改 CLI 生产授权。host 回归验证两个 wrapper 向原顶层 Parameter(0) carrier 转发；普通应用及伪造 std path/package 不取得权限，伪造 receiver 得到 L0164 且不发布 extension binding。
3. 公共 std 接线暴露既有 unit planner 缺口：`read(take(namedRoot,1))` 也把 root drop 发布在内部 take CallReturn，而非外部 read CallReturn，导致正常源码 InvalidSsa。最小修复仅在 frontend：按已验证 range-use Place origin，把 named owner 的 pending borrow 延续到 outer consumer；该调用结束时收集并解除其 pending roots，再按既有 liveness / resource 规则发布 drop。single 生产实现、backend、verifier/LLVM 均未改动。
