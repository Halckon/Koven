# F4a：Lark 离线参考工具接入审查

> **性质**：非规范依赖审查账本 · **状态**：建议有条件采用 · **读取时机**：评审 F4a 候选 Spec 或准备跨宿主复现时 · **唯一真源**：本页维护固定 wheel、风险边界、成本及复现证据

## 决策建议

将 Lark Earley 限在[F4a 候选 Spec](independent-block-diff-spec-draft.md)的有界、显式启动的离线通道。
它提供输入级歧义见证，弥补单路显式前瞻会直接作出选择的限制；它没有全局文法无冲突证明，也不替代
生产 Parser。项目现有工具能负责编排和流校验，不能凭空提供独立 Earley 解析。保持薄 token adapter，
不进入 workspace、`Cargo.lock`、默认 `cargo test`、日常 CI 或运行时。

## 包身份、许可与风险

- 来源：PyPI 固定版 `lark 1.2.2`。只用 `lark-1.2.2-py3-none-any.whl`（111,036 bytes）；
  不接受 sdist、可选 extras 或同名未固定来源。
  SHA-256：`c2276486b02f0f1b90be155f2c8ba4a8e194d42775786db622faccd652d8e80c`。
- wheel 标记 `Root-Is-Purelib: true`，未发现 `.so/.dylib/.pyd/.dll`；无必需第三方运行依赖。
  `cache` 不作为本片功能。不改 Rust edition、MSRV 或 LLVM；PyPI 声明 Python ≥3.8，不等于已验证所有版本。
- wheel 自带 MIT 许可证（Erez Shinan）。不复制或随 Koven 分发包代码；若以后分发 wheel 或改编源文件，
  保留许可并重新审查。上游在核对时有较新的 1.3.1；引用 1.2.2 仅因原型已验证，不承诺其长期最优。
  升级须重跑 token adapter、参考树和歧义负对照。
- 2026-11-18 查询 OSV（PyPI `lark` 1.2.2）及上游公开安全公告，两者均无返回项；
  不是无漏洞证明。正式接入前刷新，并核对当时的固定包来源和哈希。
- 信任边界：外部 wheel、仓库内文法和 token 流。只执行验哈希的 wheel，固定仓库中的文法，限白名单
  token 与合成测试语料；不接受用户指定文法、插件或任意文件。运行与获取分开，执行阶段不联网；
  不需要仓库写权限或凭据。进程失败、超时和越界均不是语法拒绝。

## 复现证据

1. **macOS AArch64 / Python 3.15.2**：在仓库外新建 venv；用 PyPI 下载 wheel，参数包含
   `--only-binary=:all: --no-deps --require-hashes`，再以 `--no-index --find-links` 在同一哈希约束下安装。
   `pip check` 通过，F4a 固定语料的 11 个结构比较、2 个单列语法拒绝、3 个范围外/词法拒收和
   7 个故障对照复跑通过。`PYTHONHASHSEED=0/123` 的简要输出逐字一致，不外推到完整日志。
2. **Linux x86_64 容器 / Python 3.14.4**：使用本机已有的 Koven CI 工具链镜像，显式 `--network none`
   和只读挂载 wheel；镜像缺 `ensurepip`，新建 pip venv 失败。随后以 `sha256sum -c` 验包，
   用 `python3 -I -B` 从绝对 wheel 路径加载（不安装），27 个 F3a 参考用例及双树负对照通过。
   这只验证包及参考解析在 Linux 可运行，**没有在 Linux 构建或运行生产 Lexer／Parser 差分**，
   也没有验证正式命令或仓库 CI 使用的 Python 3.12。

macOS 也复跑了同一验哈希、隔离加载路径，27 个参考用例和歧义负对照通过。
建议正式离线入口采用单一方式：预先取得 wheel，运行前核对 SHA-256，再在隔离 Python 子进程中加载。
不将 `/tmp` 探针、容器 ID 或联网安装作为交付接口。正式 Spec 仍须选定受支持的 Python 版本，并由干净
checkout 在所承诺的两类宿主跑完整命令，而不是把以上两项不同范围的证据相加。

## 成本观察与放行条件

macOS，直接构造 token 行，计参考识别和结构投影，不含 Lexer、安装或进程启动；每点三次取中位数。
`n` 分别是重复的减号操作、成员前换行或附加的块元素。

| n | 减法链 | 成员前连续换行 | 多块元素 |
|---:|---:|---:|---:|
| 8 | 2.48 ms | 1.52 ms | 5.53 ms |
| 32 | 7.47 ms | 6.90 ms | 33.71 ms |
| 64 | 15.86 ms | 11.26 ms | 98.57 ms |
| 128 | 28.53 ms | 25.78 ms | 737.63 ms |

整组 Python 进程峰值约 75 MiB，含启动和此前检查，不能归因到单个案例。多元素形状的增幅明显；
这些采样不是复杂度定理，也不能作为生产输入许可。首片只运行登记过的固定输入和 32 个模板实例；
输入经词法投影后超过 64 个事件（含 EOF）即拒绝进入参考工具，候选参考批次的总进程截止时间为 30 秒。
限制只用于离线工具。正式分支须分别实测正常语料有余量、越界明确拒绝、超时不被记作语法拒绝；
本次没有实装这两个门槛。依赖审查不等于依赖获批，不触发远端 CI。
